# RemoteScout V1 PRD

## Product
RemoteScout is a remote jobs discovery platform that brings legitimate remote job opportunities from multiple trusted sources into one organized experience.

## Core promise
Find legitimate remote jobs from trusted sources in one place.

## V1 scope
- Product foundation and landing page
- User authentication
- Protected jobs dashboard
- Job data model
- Multiple legitimate job sources
- Job aggregation pipeline
- Jobs directory
- Search and filters
- Job details
- Save jobs
- Application tracking
- Job freshness and duplicate handling
- User profile
- Admin job management

## Out of scope for V1
- Employer accounts
- Direct employer job posting
- Resume builder
- Cover-letter generator
- AI career coach
- Messaging employers
- Payments
- Premium subscriptions
- Automated job applications

## Target users
Remote job seekers across development, design, writing, marketing, community, support, sales, product, Web3, AI, and related fields.

## Core journey
Visit site → create account/sign in → access jobs dashboard → search/filter jobs → open job → review details → save or apply → track application.

## V1 build order
1. Product Foundation & Landing Page
2. Authentication
3. User Dashboard
4. Job Data Model
5. Job Sources
6. Job Aggregation Pipeline
7. Jobs Directory
8. Search & Filters
9. Job Details
10. Save Jobs
11. Application Tracking
12. Job Freshness & Duplicate Handling
13. User Profile
14. Admin Job Management
15. Final V1 Polish & Deployment

## Product principles
- Build feature by feature.
- Avoid scope creep.
- Preserve original job source attribution.
- Preserve original application URLs.
- Only use legitimate sources and permitted data access methods.
- Do not invent job listings or job information.
- Users must authenticate before accessing the jobs area.
- Start with the smallest useful implementation for each feature.
